Enchantements custom

Des enchantements rares trouvés uniquement dans les structures custom, avec une description visible sur chaque objet.

Guide joueurMis à jour avec le serveur
01

Où les obtenir

  • ◆Ils apparaissent uniquement dans les récompenses des tours, d’Alfheim, d’Asgard et des futures structures compatibles.
  • ◆Ils ne sont pas proposés par la table d’enchantement vanilla.
  • ◆Leur chance dépend du type de coffre et de la difficulté de la structure.
  • ◆Chaque enchantement affiche désormais une description d’utilisation directement dans son lore.
02

Règles de sécurité

  • ◆Flèche explosive IV produit une explosion d’impact qui inflige des dégâts sans détruire les blocs.
  • ◆Toucher de monstre, qui permettait de récupérer les spawners, a été supprimé.
  • ◆Désespoir runique V est désactivé tant que sa dimension n’est pas disponible.
  • ◆Les protections de structure continuent de s’appliquer aux effets des enchantements.
03

Bien lire un enchantement

  1. 1Lis son nom et son niveau.
  2. 2Consulte la description ajoutée sous l’enchantement.
  3. 3Vérifie le type d’objet compatible.
  4. 4Teste son effet hors d’une zone protégée si la description mentionne un impact de zone.
